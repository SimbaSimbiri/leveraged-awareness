# Leveraged Awareness

## Project Goal

This group project studies the fictional Situational Awareness long-short equity portfolio: long six AI-infrastructure stocks and short six application-software stocks, with 400% gross exposure and zero net exposure. The notebook compares equal-sleeve weights with a stabilized Sharpe-ratio optimizer through pre-2025 estimation, monthly rebalancing, turnover and constraint checks, out-of-sample performance, drawdowns, and attribution of the July 2026 reversal. A Pre-specified replacement criteria determine the final allocation.

## Data Source

`project_situational_awareness_20260731.xlsx` contains Bloomberg daily gross-dividend total-return data from 2020-2026. The analysis is in `situational_awareness_portfolio.ipynb`.
